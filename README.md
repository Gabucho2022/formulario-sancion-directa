# Acta por Faltas Leves — V4

Prototipo web de carga asistida basado en el formulario “ACTA POR FALTAS LEVES” de la Provincia de Santa Fe.

## Cambios visuales de esta versión

- Interfaz renovada con Bootstrap 5 y estética Material.
- Vue 3 integrado para componentes auxiliares de interfaz.
- Identidad visual institucional basada en el escudo presente en el formulario de referencia.
- Tarjetas, jerarquía visual, tipografía y estados mejorados.
- Vista previa del acta renovada.
- PDF con escudo, encabezado institucional y secciones de mejor lectura.

## Funcionalidad conservada

- Mismas secciones y campos de la versión anterior.
- Guardado automático local.
- Importación y exportación de borradores JSON.
- Importación de plantilla JSON.
- Tipificación asistida para art. 41 inc. b, puntos 1 a 11.
- Restricción contextual de medidas RE / AS / AA según el catálogo cargado.
- Advertencia especial en el punto 6.
- Tratamiento condicional de antecedentes disciplinarios.
- Vista previa y generación de PDF.

## Uso

Abrir `index.html` o ejecutar `iniciar.bat` en Windows. La aplicación usa CDN para Bootstrap, Vue 3, Material Symbols y jsPDF, por lo que requiere conexión a Internet para cargar esas bibliotecas.
